# 배분 규칙 정확도 보강

## 언제 쓰는지

- `web/engine.js`의 1순위 분류 정확도를 높이기 위해 배분기준표 규칙을 보강할 때 사용한다.
- 입력은 `data/배분기준표_소관키워드_304건.csv`, `data/A부_조직도_26개과.csv`, `data/시험_요구문항_40건.csv`, `data/요구자료_접수대장_2026국감_520건.csv`이다.
- 원본 규칙을 직접 고치지 않고 사용자 선택을 받은 규칙만 `rules_보강.csv`에 반영해야 하는 작업에 사용한다.

## 순서

1. `AGENTS.md`, `PROGRESS.md`, `CONTEXT.md`, `처리지침.md` 제3장을 읽는다. 원본 규칙·조직도·시험자료·접수대장을 읽고 변경 전 시험 40건과 접수대장 520건의 1순위 정확도를 계산한다.
2. 틀린 문항을 같은 일반 키워드가 여러 과에 걸리는 경우, 제외어 부족, 구체 키워드 부족, 우선순위 역전이나 동점 등 원인별로 묶는다. 각 원인에는 `제외어 추가`, `키워드 추가`, `우선순위 변경` 중 가장 좁은 수정안 하나만 제안한다.
3. 제안만으로 규칙을 바꾸지 않는다. 사용자가 고른 방법을 확인한 뒤 원본 배분기준표를 `rules_보강.csv`로 복사하고 선택한 셀만 수정한다. 새 규칙의 과는 조직도 26개 과 안에 있어야 한다.
4. 원본 규칙과 보강 규칙으로 시험 40건과 접수대장 520건을 각각 다시 실행한다. 변경 전·후 1순위 정답 수, 새로 맞은 문항, 기존에 맞았다가 새로 틀린 문항을 비교한다. 규칙 수가 유지되고 사용자 선택 외의 셀이 바뀌지 않았는지도 검사한다.
5. 변경 규칙과 검증 결과를 `PROGRESS.md`에 기록하고 사용자에게 표로 보고한다. 시험 1순위가 30/40 이상이고 두 검증 자료에서 새로 틀린 문항이 0건일 때만 정확도 보강이 성공했다고 판정한다.

## 끝나는 조건

- `rules_보강.csv`가 존재하고 원본 배분기준표는 변경되지 않았다.
- 사용자가 고른 규칙만 변경됐으며 모든 과가 조직도 26개 과에 포함된다.
- 변경 전·후 정확도 표에 시험 40건과 접수대장 520건의 1순위 결과가 모두 있다.
- 시험 1순위 정답이 30건 이상이고 새로 틀린 문항이 0건이다.
- 변경 규칙, 정확도와 남은 일이 `PROGRESS.md`에 기록됐다.

## 하지 말 것

- 사용자가 선택하지 않은 제외어·키워드·우선순위를 임의로 반영하지 않는다.
- 원본 `data/배분기준표_소관키워드_304건.csv`, 조직도, 시험자료와 접수대장을 수정하지 않는다.
- 배분 규칙이나 특정 문항의 정답을 엔진 코드에 직접 쓰지 않는다.
- 조직도에 없는 과를 만들거나 후보로 추가하지 않는다.
- 정확도만 높이기 위해 기존 정답의 새 오답을 숨기거나, 새 오답이 있는데 성공으로 보고하지 않는다.
