# 자료요구서 문항 분해

`원문/`의 자료요구서 PDF를 읽어 폴더 맨 위에 `split.py`를 만들고, `data/문항목록.csv`를 생성한다. 사용자가 교체하거나 교정한 문항목록이 있으면 이를 정답본으로 삼아 `split.py`의 결과가 전부 일치하도록 고친다.

## 준비

1. `AGENTS.md`, `PROGRESS.md`, `CONTEXT.md`를 읽고 `CONTEXT.md`가 가리키는 `처리지침.md` 제2장과 원문 PDF를 직접 확인한다.
2. `pypdf` 설치 여부를 먼저 확인한다. 없으면 `pip install pypdf`를 사용자에게 보여 주고, 허락을 받은 뒤 설치한다.
3. 원문 PDF와 기존 `data/` 파일은 수정하지 않는다. 교정된 `data/문항목록.csv`도 덮어쓰지 않는다.

## 분해 규칙

- 첫 줄 `○○위원회 ○○ 의원실 자료요구서`에서 위원회와 의원을 추출한다.
- `수신: … 제출기한: YYYY. M. D.(요일) HH:MM까지` 줄에서 날짜를 찾아 `YYYY-MM-DD`로 저장한다.
- `수신:`, `담당 보좌관:`, 연락처와 `끝.`은 결과에 넣지 않는다. 이름과 연락처를 별도로 저장하지 않는다.
- 줄 맨 앞의 `숫자.`는 새 문항으로 처리한다.
- `가.`, `나.` 등은 앞 문항의 세부항목으로 처리하고 원문 순서대로 ` / `로 연결한다.
- `※` 줄은 앞 문항의 비고로 처리한다. 비고 값에는 선두의 `※`와 뒤 공백을 제거한다.
- 그 밖의 줄은 바로 앞에서 활성화된 요구내용·세부항목·비고에 이어 붙인다.
- PDF 처리에는 `pypdf`만 사용한다. 생성 코드는 `split.py` 하나로 둔다.

## 출력

- 경로: `data/문항목록.csv`
- 인코딩: `utf-8-sig`
- 열 순서: `파일명 | 위원회 | 의원 | 제출기한 | 문항번호 | 요구내용 | 세부항목 | 비고`
- 기존 출력 파일이 있으면 사용자의 명시적 지시 없이 덮어쓰지 않는다.

## 교정본 반영 절차

1. 기존 `split.py`의 `parse_pdf()` 결과를 메모리에서 생성한다.
2. 교정된 `data/문항목록.csv`와 행·열별로 비교해 차이가 난 위치와 유형을 찾는다.
3. 개별 문항 값을 코드에 직접 쓰지 않는다. 차이를 설명하는 일반 파싱 또는 정규화 규칙으로 `split.py`를 수정한다.
4. 다시 추출해 교정본의 행 수, 열 수와 모든 셀이 일치하는지 확인한다.
5. 교정본은 비교용으로만 읽고 수정하거나 다시 저장하지 않는다.

## 확인

각 PDF에 대해 다음 표를 보고한다.

`파일명 | 파일명의 문항 수 | 뽑은 문항 수 | 마지막 번호 | 번호 연속 | 일치(O/X)`

- 파일명에서 기대 문항 수를 추출한다.
- 뽑은 문항 수와 마지막 번호를 계산한다.
- 번호가 1부터 마지막 번호까지 빠짐없이 연속인지 검사한다.
- 기대 문항 수, 뽑은 문항 수, 마지막 번호와 연속성이 모두 맞을 때만 `일치`를 `O`로 표시한다.
- `일치`가 `X`이면 원인을 찾아 `split.py`를 고친 뒤 다시 실행한다.
- 수신·담당 보좌관·연락처·`끝.` 저장 건수가 모두 0인지 검사한다.
- 세부항목과 비고가 있는 문항 3개를 골라 원문 PDF 내용과 CSV 결과를 나란히 보여 준다.
- 교정본이 있으면 3개 표본 대조에 더해 전체 행·열의 모든 셀이 일치해야 완료한다.

## 마무리

`PROGRESS.md`에 날짜, 단계, 변경 파일, 검증 건수, 남은 일과 막힌 점을 기록한다.
