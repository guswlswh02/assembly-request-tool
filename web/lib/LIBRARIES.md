# 브라우저 라이브러리

| 라이브러리 | 버전 | 사용 위치 | 용도 |
|---|---:|---|---|
| Papa Parse | 5.7.0 | `common.js`, `engine.js` | CSV 읽기 |
| Fuse.js | 7.5.0 | `assign.html` | 유사 문항 검색 |
| Tabulator | 6.7.1 | `assign.html` | 접수 미리보기와 배분 표 |
| pdf.js | 5.6.205 | `assign.html` | PDF 글자 추출 |

각 라이브러리는 같은 폴더의 라이선스 파일과 함께 보관한다. SheetJS와 Chart.js는 엑셀 취합과 현황 차트가 필요한 S8 화면을 구현할 때 추가한다.
